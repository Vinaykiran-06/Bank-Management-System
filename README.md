# 🏦 Bank Management System (Python)

A console-based Bank Management System built using Python.  
This project focuses on Object-Oriented Programming, file handling, and data persistence using JSON.

## 🚀 Features

- Create new bank accounts
- Automatic account number generation
- Deposit money
- Withdraw money
- Check account balance
- PIN verification
- Transaction history tracking
- Money transfer between accounts
- Date and time transaction records
- Save account data using JSON
- Load previous account data when the program starts

## 🛠️ Technologies Used

- Python
- Object-Oriented Programming (OOP)
- JSON
- File Handling
- Datetime Module
